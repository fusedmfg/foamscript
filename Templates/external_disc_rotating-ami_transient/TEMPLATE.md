# External Rotating Disc Template (AMI, Transient)

**Template Name**: `external_disc_rotating-ami_transient`

**Classification**:
- **Domain**: External aerodynamics
- **Feature**: Rotating disc (frisbee, propeller blade element, etc.)
- **Motion**: AMI (Arbitrary Mesh Interface) - full mesh rotation
- **Solver**: Transient (pimpleFoam)

This template is designed for rotating disc simulations with angle of attack (AoA) sweeps in external flow. It uses [Scriban](https://github.com/scriban/scriban) templating to dynamically generate case files with calculated parameters.

## Template System

FoamScript processes this template using `TemplateService`, which recursively processes all files and replaces Scriban variables (e.g., `{{ variable_name }}`) with calculated values. The template context is generated in `CaseService.CalculateTemplateContext()`.

## Template Variables

All template variables use lowercase with underscores (e.g., `{{ ux }}`, `{{ omega_rotation }}`).

### Primary Input Parameters

These are directly set from command-line arguments:

| Variable | Type | Description | Source |
|----------|------|-------------|--------|
| `ux` | double | X-component of velocity (m/s) | Calculated from velocity magnitude and angle |
| `uz` | double | Z-component of velocity (m/s) | Calculated from velocity magnitude and angle |
| `omega_rotation` | double | Disc rotation speed (rad/s) | Converted from RPM |
| `cores` | int | Number of CPU cores for parallel execution | User input |
| `disc_diameter` | double | Disc diameter (m) | Extracted from geometry bounding box |

### Derived Turbulence Parameters

Calculated using standard turbulence models:

| Variable | Type | Description | Formula |
|----------|------|-------------|---------|
| `k` | double | Turbulent kinetic energy (m²/s²) | `1.5 × (velocity × turbulence_intensity)²` |
| `omega_turbulence` | double | Specific dissipation rate (1/s) | `√k / (Cmu^0.25 × mixing_length)` |
| `mixing_length` | double | Turbulence mixing length (m) | `0.07 × disc_diameter` |

### Constants

| Variable | Type | Value | Description |
|----------|------|-------|-------------|
| `p` | double | 0 | Reference pressure (Pa) |
| `turbulence_intensity` | double | 0.05 | 5% turbulence (standard for clean air flow) |
| `cmu` | double | 0.09 | k-omega SST turbulence model constant |
| `nu` | double | 1.5e-05 | Kinematic viscosity (m²/s, standard air) |
| `end_time` | double | 1.0 | Simulation duration (seconds) |
| `n_outer_correctors` | int | 3 | PIMPLE solver stability parameter |
| `refinement_level_min` | int | 3 | snappyHexMesh minimum refinement level |
| `refinement_level_max` | int | 4 | snappyHexMesh maximum refinement level |

### Computed Values

| Variable | Type | Description | Formula |
|----------|------|-------------|---------|
| `mag_u_inf` | double | Free stream velocity magnitude (m/s) | `√(ux² + uz²)` |
| `aref` | double | Reference area for force coefficients (m²) | `π × (disc_diameter / 2)²` |

## Templated Files

The following files contain Scriban template variables:

### Initial Conditions (`0/`)

| File | Variables | Description |
|------|-----------|-------------|
| `U` | `ux`, `uz` | Velocity field (inlet and rotor boundaries) |
| `p` | `p` | Pressure field (outlet boundary) |
| `k` | `k` | Turbulent kinetic energy field |
| `omega` | `omega_turbulence` | Specific dissipation rate field |

### Physical Properties (`constant/`)

| File | Variables | Description |
|------|-----------|-------------|
| `transportProperties` | `nu` | Kinematic viscosity |
| `dynamicMeshDict` | `omega_rotation` | Disc rotation speed |

### Solver Configuration (`system/`)

| File | Variables | Description |
|------|-----------|-------------|
| `controlDict` | `end_time`, `mag_u_inf`, `disc_diameter`, `aref` | Simulation time control and force coefficients |
| `decomposeParDict` | `cores` | Parallel decomposition |
| `fvSolution` | `n_outer_correctors` | PIMPLE solver parameters |
| `snappyHexMeshDict` | `refinement_level_min`, `refinement_level_max` | Mesh refinement levels |

## Non-Templated Files

These files are copied as-is without variable substitution:

- `0/nut` - Turbulent viscosity (wall functions handle this)
- `constant/g` - Gravity vector
- `constant/turbulenceProperties` - Turbulence model selection
- `system/blockMeshDict` - Background mesh definition
- `system/fvSchemes` - Discretization schemes
- `system/surfaceFeatureExtractDict` - Feature edge extraction

## Geometry Files

STL files are copied separately after template processing:

- `constant/triSurface/disc.stl` - Main disc geometry
- `constant/triSurface/rotor.stl` - Rotating zone
- `constant/triSurface/tunnel.stl` - Wind tunnel domain

These are generated by `GeometryService` and copied by `CaseService.CopyStlFiles()`.

## Usage Example

```csharp
// In CaseService.cs
var context = CalculateTemplateContext(ux: 19.3, uz: 1.74, omegaRotation: 104.7, cores: 8, discDiameter: 0.211);
_templateService.ProcessTemplate(templatePath, outputDir, context);
```

The template processor:
1. Recursively walks all files in the template directory
2. Parses each file as a Scriban template
3. Renders the template with the provided context
4. Writes the processed content to the output directory

## Maintaining This Template

When modifying template files:

1. **Adding a new variable:**
   - Add the variable to `CaseService.CalculateTemplateContext()`
   - Use `{{ variable_name }}` in template files
   - Document it in this file under the appropriate section

2. **Modifying existing parameters:**
   - Update the calculation in `CalculateTemplateContext()`
   - Update this documentation
   - No changes to template files needed unless renaming

3. **Adding a new templated file:**
   - Create the file with `{{ }}` syntax where needed
   - Document it in the "Templated Files" section above

4. **Adding a non-templated file:**
   - Create the file without `{{ }}` syntax
   - Document it in the "Non-Templated Files" section above
